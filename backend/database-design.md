## ID Strategy

- Primary keys use UUIDv7.
- IDs are generated by the application.
- Public short codes are separate from internal IDs.
- Short codes use a Base62-compatible representation.
- Short codes must not be predictable.
- Short codes must never be reused.

## Short Code Registry

A dedicated registry preserves historical short codes even
after the corresponding link is physically deleted.
This guarantees that a previously issued short code can
never be assigned to another link.
